# Android Self-Test App

Personal Android testing app with Firebase integration.

## ⚠️ Disclaimer

For **personal device testing only**. Do NOT install on anyone else's device.

## Permissions

- SMS (read/send/receive)
- Call Log
- Media/Gallery

## Setup

1. Clone this repo
2. Add your own `google-services.json` in `app/` folder
3. Open in Android Studio
4. Build & run

## Firebase

- Project: indusind-c9c8c
- Database: Realtime Database
- Package: `Indusind.com`
